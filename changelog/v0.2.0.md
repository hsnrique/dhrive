date: 2026-09-29
title: The new dhrive
---
dhrive is now a Mac app that gives every coding request two models: one plans, another writes the code, from the CLIs you already use.

- Plan with one CLI and model, code with another: Claude Code, Codex (including the copy inside the ChatGPT app) and open-weight models through Ollama.
- Local models are sized to your Mac before they download, and install in one click.
- Model lists come from each CLI, so new models show up without a dhrive update.
- Three modes: **Chat** to think it through, **Plan** for a plan then the code, **Code** to go straight to it.
- When the planner needs answers, it asks instead of guessing.
- Context carries over: each project picks up its CLI sessions, including ones you started in the Claude app, the terminal or Codex.
