title: What each task spends
---
- **Tokens per task**: every task shows what its runs spent, as its CLI counted them, with the breakdown (the task, its fixes, the review) and how much came from the cache. The tasks section shows the total, and the Army each agent's.
- **Lean**, on by default: agents work without narrating and close with one line, what changed and which checks passed. In 32 runs on Claude Code and Codex, the closing text came out a third to two thirds shorter, and every task was still done.
- **Sharper reviews**: the reviewer no longer reads lockfiles and build output, only their names, so the review goes to the code that was written.
