### A fourth CLI
- Antigravity joins Claude Code, Codex and local models. Plan with Gemini and code with Claude, or any other mix: its models come straight from `agy`.

### See it working
- A Browser tab beside the conversation shows your project's dev server. dhrive finds it by itself and reloads it when a code step ends.

### Safer in parallel
- Conversations already run side by side. Now two code steps in the same project take turns, so one never edits over the other or undoes its work.
