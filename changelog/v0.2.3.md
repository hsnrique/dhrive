### A second way to work
- Switch to Terminals at the top of the sidebar and run up to six CLIs side by side: Claude Code, Codex and Antigravity, each as itself, each in a project of yours.
- Every pane shows when its CLI is working, when it's your turn, and the task it's on. A pane that needs you while dhrive is in the background sends a notification.

### Never step on each other
- Give a pane a copy of its own and it works in a git worktree on its own branch, so two panes on one project never edit the same files.
- Turning the copy off removes it, unless it holds work that isn't committed yet. Then it stays where it is, and dhrive tells you where.
