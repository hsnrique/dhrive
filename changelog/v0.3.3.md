title: Quality on every delivery
---
- **Checks on every delivery**: after each task, dhrive runs the company's lint, typecheck, tests and build itself. A failing one goes back to the agent to fix; only a passing delivery is done.
- **A standard for the code**: every company's agent follows the same architecture and quality rules, and keeps the project's architecture written down.
- **A model per company**: pick the agent from the tasks bar whenever you want; waiting tasks follow the new pick.
- **Environment**: each company keeps its variables in your Keychain. Agents, terminals and Play get them, the published site gets only the public ones, and a removed one can be put back.
- **Ask first** is off by default and can be set when founding. Off, the agents run without stopping for approvals, and an MCP tools switch decides whether they reach your MCP servers.
- **Feedback** and the **Discord community** are a click away in the sidebar.
