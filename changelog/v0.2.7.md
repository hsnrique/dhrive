### The maestro
- Each pane's copy now lives inside the project folder, hidden from git, so its CLI builds and runs the app where your project is.
- Bring together merges the panes' work into the project folder itself, on a branch of the session's own when you're on main, so the result is right where you work.
- Resolving a conflict or looking the result over opens in the project folder too.
